The user (enzozhang2000@gmail.com, GitHub Xiaoyi-ZHANG23 "Xiaoyi Zhang") is a
developer/maintainer of **gRASPA** (https://github.com/snurr-group/gRASPA), a
GPU-accelerated grand-canonical Monte Carlo code for adsorption in nanoporous
materials (zeolites and MOFs). They merge PRs into snurr-group/main from their
fork. Works on force-field features (e.g. 12-6-4 LJ / `UseLJ1264`), zeolites vs
MOFs, ML interatomic potentials (Allegro, MACE, GemNet), AutoJIT. Comfortable at
the C++/CUDA source level; expects rigorous empirical verification (build + run +
bit-level diff), not just code reading. See [[graspa-build-and-test]].
